Full description

For our customers from the technically demanding environment in Dattwil, we are looking for an experienced system engineer IT infrastructure. In this versatile role, you will manage physical and virtual IT environments for development and testing, and help with installations in the lab and server room.

Your tasks

  • Management of VMware environments with virtual machines, templates and ESXi hosts
  • Provision, maintenance and troubleshooting of physical and virtual test environments
  • Administration of Windows Server, Active Directory, Group Policy and DNS
  • Installation and configuration of Microsoft SQL Server and IIS
  • Installation of servers, storage and network hardware as well as rack assembly and cabling in the laboratory and server room
  • Verification of network connections and access rights in cooperation with infrastructure and network teams
  • Perform installations, upgrades and resets, and analyze disruptions across infrastructure and applications
  • documentation of configurations, installation processes and solutions
  • Automation of recurring tasks with PowerShell

Your profile

  • Several years of experience as a system engineer with in-depth knowledge of VMware and ESXi
  • Very good knowledge of Windows Server, Active Directory, Group Policy and DNS
  • Experience with Microsoft SQL Server and IIS
  • Solid network understanding: TCP/IP, VLANs, NTP, NAT, routing and firewall connectivity
  • Practice with server hardware, storage and network technology, ideally Dell switches and iDRAC
  • Experience with PowerShell and enjoyment of practical work in the lab and server room
  • Very good English skills are mandatory, good German is an advantage
  • Knowledge of Ansible, Git, Azure DevOps, Linux or Citrix is an advantage
